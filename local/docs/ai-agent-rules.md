# AI Агент — Правила роботи з Канбаном

> Ці правила завантажуються в системний промпт AI агента (`local/src/routes/agent.js`).
> Оновлювати тут та синхронно в `SYSTEM_PROMPT` у agent.js.

---

## Типи карток канбану

| Тип      | Призначення                                              | Вигляд            |
|----------|----------------------------------------------------------|-------------------|
| `idea`   | Ідея / концепція / задум, що потребує реалізації         | Золота рамка 💡   |
| `task`   | Конкретний крок реалізації                               | Стандартна картка |
| `subtask`| Деталізований крок всередині задачі                      | Відступ ↳         |

---

## Правило № 1 — Збереження контексту ідеї

Коли користувач ділиться ідеєю, концепцією або задумом:

1. **СПОЧАТКУ** — один запис типу `idea`:
   - `title` — коротка суть ідеї (1 рядок)
   - `description` — **ПОВНИЙ контекст**: що це, навіщо, яка проблема вирішується, очікуваний результат, нотатки розмови
   - `column` — `"idea"`

2. **ПОТІМ** — окремі записи типу `task` для кроків реалізації:
   - Кожна задача = один конкретний виконуваний крок
   - `description` — деталі реалізації цього кроку
   - Пов'язати з ідеєю через `linkedTaskIds`

### Чому так?
- Ідея повинна бути "єдиним місцем правди" — весь задум зберігається в ній
- Кроки виконання — окремі виконувані задачі, якими можна рухати по колонках
- Контекст не губиться при переміщенні карток

---

## Правило № 2 — Коли NOT створювати ідею

Якщо користувач каже "додай задачу X" або "нагадай зробити X" — це `task`, не `idea`.

Ідея = щось, що потребує обміркування, планування, контексту.
Задача = щось конкретне і зрозуміле.

---

## Правило № 3 — Підзадачі

Якщо задача виявляється занадто великою:
- Створюй `subtask` записи з `parentTaskId` = id батьківської задачі
- Підзадача завжди прив'язана до одної задачі

---

## Правило № 4 — Зв'язки між задачами

- Використовуй `link_tasks` для зв'язування існуючих карток
- При створенні — `linkedTaskIds` одразу вказує пов'язані
- Зв'язок двосторонній (автоматично додається в обидві картки)

---

## Приклад

**Користувач:** "Хочу зробити систему автоматичного поливу саду"

**AI:** Створює:
1. `idea` — "Система автоматичного поливу саду"
   - description: "Мета: автоматизувати полив ділянки. Зараз полив вручну кожен день займає 20 хв. Хочу: датчики вологості + таймер + клапани. Розглядаємо ESP32 + HA інтеграцію. Бюджет ~$100."
   - linkedTasks: [id задачі 1, id задачі 2, ...]

2. `task` — "Вибрати контролер (ESP32 vs Arduino)"
   - linkedTaskIds: [id ідеї]

3. `task` — "Закупити датчики вологості та клапани"
   - linkedTaskIds: [id ідеї]

4. `task` — "Написати прошивку для ESP32"
   - linkedTaskIds: [id ідеї]

5. `task` — "Інтегрувати з Home Assistant"
   - linkedTaskIds: [id ідеї]
